# Ramo de flores moradas

React + Vite + Tailwind CSS + Framer Motion.

    npm install
    npm run dev       # desarrollo
    npm run build     # genera /dist

Textos, tipografías y posiciones: `src/data/phrases.js`.
Publicar: sube el proyecto a GitHub e impórtalo en vercel.com (Framework: Vite), o usa `npx vercel`.
